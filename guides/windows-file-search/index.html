Guide · seekfs 1.12.1

Find files on Windows
from the command line

Index a folder or an NTFS volume, then query names and paths without walking the drive. The example creates a small folder index so you can run every step.

Before you start

The folder example takes about two minutes. A whole-volume index can take longer.

  • Windows 10 or 11. NTFS is the primary target for volume indexes.
  • The seekfs 1.12.1 ZIP from the latest release.
  • Administrator PowerShell for a volume index or service management. The folder index below does not need administrator access.
  • No Everything install. The comparison on the product page is a separate benchmark.

1. Download and extract

Use the Windows ZIP from the latest release. The archive contains seekfs.exe, seekfs-native.exe, and seekfs-ui.exe.

The binaries are unsigned. Windows may show a security prompt.

Windows x64 · PowerShell
Invoke-WebRequest https://github.com/holdfast-labs/seekfs/releases/download/v1.12.1/seekfs-windows-amd64.zip -OutFile seekfs-windows-amd64.zip
Expand-Archive seekfs-windows-amd64.zip -DestinationPath seekfs
Set-Location seekfs

2. Create a small folder

The example uses a folder index so you can test the query language without indexing a whole drive. It creates two folders and three files.

Use your own folder after the first run.

Create the fixture
$demo = "$env:USERPROFILE\seekfs-demo"
New-Item -ItemType Directory -Force "$demo\reports","$demo\src" | Out-Null
Set-Content "$demo\reports\quarterly-report.txt" "Q3"
Set-Content "$demo\reports\draft-report.txt" "Draft"
Set-Content "$demo\src\main.go" "package main"

3. Build the folder index

index writes a database file. Later commands read it with -db.

The resident service is the faster option for daily use. This folder index is the smallest complete example.

Build the index
.\seekfs.exe index -root $demo -db .\demo.gsi
Example output · small folder tree
indexed 6 entries in 6ms

4. Search names and paths

Filename search is the default. Put flags before the query and quote multi-term queries.

The result includes directories and files. Add a filename term or -path when you need narrower results.

Search the folder index
.\seekfs.exe search -db .\demo.gsi report
Example output · directory and files
C:\Users\you\seekfs-demo\reports
C:\Users\you\seekfs-demo\reports\draft-report.txt
C:\Users\you\seekfs-demo\reports\quarterly-report.txt

5. Ask for JSON and a count

--json returns the query, count, limit, completeness flag, and results. Use -n to bound the row count.

!draft excludes the draft file. The count command returns a number only.

JSON and count
.\seekfs.exe search -db .\demo.gsi --json -n 2 "report !draft"
.\seekfs.exe count -db .\demo.gsi "ext:go"

6. Use a resident volume index

For daily search, build a resident index for an NTFS volume and launch the service. Run this in an administrator PowerShell in the extracted folder.

You can also open seekfs-native.exe (the primary desktop app) or seekfs-ui.exe (the previous web-view UI), tick drives under Settings > Drives, keep "Install the seekfs service" checked, and click Apply.

Then query without -db. The CLI uses the resident service.

Volume index and service
.\seekfs.exe index-volumes -volume C: -launch
.\seekfs.exe search main
.\seekfs.exe search --under C:\git\project main.go
.\seekfs.exe count "ext:md"

Query terms that narrow a result set

Filters are query terms. Combine them with a filename term to keep a result set small.

  • ext:go matches an exact file extension.
  • dir:cmd matches a path substring. Use -path when terms can appear in the directory part.
  • in:src or --under C:\git\project scopes the search to a subtree.
  • glob:*.py matches a file name. A pattern with / or ** matches the full path.
  • size:>100mb and dm:today filter by metadata.
  • git:modified narrows results to a Git status.
  • --exists checks that each path still exists.

Use it from a script or agent

Scope the search before you raise the limit. A broad query can return thousands of rows.

--exists calls os.Stat and is slower. Use it when stale index entries matter.

The JSON reply includes ok, query, count, limit, complete, and results.

Agent-safe forms
.\seekfs.exe search --json --under C:\git\project main.go
.\seekfs.exe count -path "ext:go dir:cmd main"
.\seekfs.exe search -path --exists --recent 24h "ext:go"
.\seekfs.exe config set output_format json
.\seekfs.exe config set default_limit 20
.\seekfs.exe defaults --json

Know the limits

  • Windows and NTFS are the primary target. Ranking is simple.
  • Size, date, and attribute filters need metadata captured by the index. Older indexes without it return an error.
  • A newly created directory may report zero size until it is folded into the base index.
  • Index files contain local path names. Treat them as local metadata.
  • This guide searches names and paths. Run .\seekfs.exe syntax for the current query surface, and use wgrep or ripgrep for code search.
