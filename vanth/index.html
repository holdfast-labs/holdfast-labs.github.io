02 / Background jobs for agents

vanth.

Agents start the work. Vanth brings back the result.

Long builds, test suites and benchmarks run as durable background jobs. When one finishes, vanth wakes the agent that asked.

How it works

Hand it off. Get woken up.

Ask

Tell your agent to run the job with Vanth. It launches through vanth's MCP tools.

Run

The job runs in the background while vanth records its output, metrics and events.

Wake

When it finishes, vanth delivers the completion event back to the agent. No polling.

Monitor

Watch the work.

vanth-monitor shows every job live: progress, plots, metrics and the event stream.

vanth-monitor
