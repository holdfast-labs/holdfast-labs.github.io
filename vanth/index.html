Agent-driven.
From start to finish.

Jobs keep running independently.
The result returns to the agent that asked.

  1. Hand off the job

    The agent uses MCP, or the CLI with --wake-me, to start a detached command.

  2. Keep the context

    Output, progress and checkpoints stay with the job. The agent can go idle.

  3. Wake with the result

    vanth resumes the OpenCode or Codex session with the outcome attached.
