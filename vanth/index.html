vanth.

Let the work run. Stay in the loop.

A localhost job daemon with an MCP interface. Start detached commands, keep output and events in durable SQLite state, and wake a Codex or OpenCode session when a job needs attention.

Get started / 03

Start a job. Follow the signal.

With Python's uv installed, run this complete PowerShell example. Add the MCP integration when your agent workflow is ready.

# Install the CLI and MCP server
uv tool install vanth

# Run a detached job and inspect its saved output
$job = (vanth start --json --name demo -- ping -n 5 127.0.0.1 | ConvertFrom-Json).job_id
vanth status $job
vanth wait $job --events completed,failed
vanth logs $job
