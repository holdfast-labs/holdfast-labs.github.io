seekfs

Instant file search for Windows.
A desktop app for you. JSON for your agents.

Download for WindowsSource
Windows x64 · MIT

Recorded on Windows 11.Use fullscreen for a closer look.

Built for agents, too.

Find the right files before reading them. Scope the search, bound the results, return structured JSON.

  • seekfs agent: built-in guidance.
  • --under: stay in your workspace.
  • count --json: get the match count.
  • --exists: filter stale paths.
