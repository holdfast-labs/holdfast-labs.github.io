Get started / 03

One small index. Immediate answers.

On Windows with Git and Go installed, run this in PowerShell. The resident service is available later for full-volume indexing.

# Get the public source and build the CLI
git clone https://github.com/holdfast-labs/seekfs.git
cd seekfs
go build -o seekfs.exe ./cmd/seekfs

# Index this repo and find a specific file
.\seekfs.exe index -root . -db .\repo.gsi
.\seekfs.exe search -db .\repo.gsi -path "ext:go dir:cmd search_cli"
.\seekfs.exe count -db .\repo.gsi "ext:go"
