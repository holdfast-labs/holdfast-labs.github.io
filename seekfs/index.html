Get started / 03

One small index. Immediate answers.

Try seekfs on a folder first. The resident Windows service is available when you want full-volume indexing.

# Build from source
go build -o seekfs.exe ./cmd/seekfs

# Index a folder, then search it
.\seekfs.exe index -root .\project -db .\project.gsi
.\seekfs.exe search -db .\project.gsi -path "ext:go dir:cmd main"
.\seekfs.exe count -db .\project.gsi "ext:md"
