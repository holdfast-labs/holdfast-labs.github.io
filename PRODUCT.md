# Holdfast Labs

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers and coding agents evaluating local tools. The owner is building a bootstrapped software studio and explicitly wants agent-facing capabilities to be prominent.

## Product Purpose

Host Holdfast Labs projects together, with clear downloads, source links and actual demonstrations.

## Capabilities and Constraints

- seekfs searches indexed Windows file names and paths from a desktop UI, CLI and resident service. Its agent-facing features include JSON, workspace scoping and bounded results. It is not file-content search.
- vanth runs background jobs and returns results to coding agents, including wake flows for OpenCode and Codex. Demonstrations must show the actual products, including vanth-monitor.
- Preserve existing repository URLs, release links, real recordings and benchmark data. Do not invent claims, customers or results.
- Static HTML, CSS and JavaScript, published through GitHub Pages. No new framework is needed.

## Brand Commitments

Holdfast Labs is the name. The owner wants minimal copy, distinctive integrated animation, product pages under a Products dropdown and a restrained homepage. SpaceFS is the current visual reference; Astral was an earlier reference. Avoid a generic agent-generated landing page.

## Evidence on Hand

Actual seekfs UI and CLI recordings, OpenCode/Codex wake recordings, vanth-monitor recordings and `assets/seekfs-vs-everything.json`. The benchmark is a 20,000-file fixture, 90 complete CLI runs per query on one Windows PC, not an industry-wide performance conclusion.

## Product Principles

Use actual products as proof. Keep installation direct. Explain agent capabilities concretely. Keep marketing text short.
