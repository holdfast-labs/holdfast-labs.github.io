What's new

Highlights from recent seekfs, vanth, and wgrep releases. Full notes ship with every tag on GitHub.

wgrep 0.3.0October 27, 2026

Scoped semantic search

Search part of a repository, filter semantic files, and set an explicit relevance cutoff.

  • Pass a file or directory to limit semantic search within the attached root.
  • Repeat --semantic-glob to include files; prefix ! to exclude.
  • --min-score keeps chunks at or above a raw cosine score. There is no default cutoff.
  • Status separates pending rescans from active work and reports live text counts.
vanth 1.12.3September 23, 2026

Agent usability

Smaller surprises for agents and first-time users.

  • vanth wait and --wake-me now cover every terminal outcome by default: completed, failed, timeout, cancelled and orphaned.
  • Every MCP tool has a description, and the tool reference is grouped by task.
  • vanth doctor summarizes relays and highlights failed deliveries.
  • First-run vanth setup creates a missing client config before registering.
vanth 1.12.0September 23, 2026

Zero-JSON wakes

Be woken when a job finishes without writing wake-target JSON by hand.

  • vanth start --wake-me and job_start(wake_me=True) resolve the live session for the job's folder.
  • Start responses echo the resolved wake targets, so the caller can confirm who will be woken.
  • Wake targets on remote jobs register locally and fire when the remote job emits a matching event.
  • vanth start refuses commands reassembled around bare shell operators instead of running them wrong.
seekfs 1.10.3Maintenance

Cleaner names

An internal refactor and test-coverage release; search, indexing and the service behave as in 1.10.2.

  • The direct builder subcommand is now direct; direct-v9 still works.
  • Service variables dropped the V9 qualifier: SEEKFS_*. Old spellings are still read.
  • Removed the no-op -skip-startup-sync flag.
seekfs 1.10.2Fix

No more fold loops

A torn write-ahead-log tail, left by a persist killed mid-append, blocked the post-fold WAL rewrite and sent the service into back-to-back folds. The rewrite now tolerates it.

vanth 1.11.0September 22, 2026

Wake a job after it started

  • vanth wake <job> adds a wake target to a running or finished job; --now fires one immediately.
  • --wake, --trigger and --policy accept @file or stdin, so PowerShell 5.1 quoting can't corrupt nested JSON.
  • Relay client ids are rejected as wake destinations instead of sitting pending forever.
seekfs 1.10.1Fix

The service stops watching itself

Measured on a live index, 91.7% of pending changes came from seekfs's own index, log and WAL files. They are now dropped before they reach the log, and the persist trigger scales with index size.

seekfs 1.10.0Performance

Rebuilds up to 7× faster

  • A 17.1M-record volume rebuilds in about 1m 54s instead of 13m 06s, at 4.4 GiB peak instead of 8.5.
  • Name trigrams build with bounded memory by default.
  • regex: queries pre-filter on the literal text every match must contain.
vanth 1.10.0September 17, 2026

OpenCode wakes in the TUI

  • vanth setup installs an in-process OpenCode plugin, so wakes reach a plain opencode terminal session.
  • vanth start, vanth wait, vanth deliveries and vanth api give a full workflow without MCP.
  • Every subcommand gets --help, and job ids accept unambiguous prefixes.
vanth 1.9.0September 10, 2026

Operational hardening

  • vanth backup and vanth restore archive jobs, artifacts and events safely while the daemon runs.
  • An authenticated Prometheus endpoint and edge-triggered operator alerts.
  • One outbound policy for webhooks and probes that refuses link-local and cloud-metadata destinations.
seekfs 1.9.0Feature

Live sizes and dates

Files changed on disk are re-read when the journal reports them, so sizes and modification times stay current, and folder sizes update live up the tree.

seekfs 1.8.0Feature

Recursive folder sizes

Folders report the total size of their contents, and size: filters match folders by that total.
